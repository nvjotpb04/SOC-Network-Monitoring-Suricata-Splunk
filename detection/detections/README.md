
# Detection Analysis

This directory contains documentation for analyzing Suricata security
alerts through Splunk Enterprise.

## Detection Areas

The SOC monitoring dashboard provides visibility into:

- Suricata alert signatures
- Source IP addresses
- Destination IP addresses
- Destination ports
- Alert severity
- Alerts over time
- Network protocols
- HTTP methods

## SOC Analyst Approach

When an alert is identified, the analyst can:

1. Review the Suricata alert signature.
2. Identify the source IP address.
3. Identify the destination IP address.
4. Review the destination port.
5. Check the network protocol.
6. Review HTTP activity when applicable.
7. Check alert severity.
8. Analyze the event timeline.
9. Correlate related events.
10. Document the investigation findings.
