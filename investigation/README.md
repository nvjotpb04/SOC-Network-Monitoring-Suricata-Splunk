
# Incident Investigations

This directory contains security alert investigation documentation
based on events observed through the SOC monitoring environment.

## Investigation Process

1. Identify the security alert.
2. Review the Suricata alert signature.
3. Identify the source IP address.
4. Identify the destination IP address.
5. Review the destination port.
6. Analyze the network protocol.
7. Review HTTP activity when applicable.
8. Check the alert severity.
9. Analyze the event timeline.
10. Correlate related security events.
11. Determine whether the activity is suspicious.
12. Document the investigation findings.

## Investigation Scenarios

The project will document investigations such as:

- Suspicious source IP activity
- Repeated Suricata alerts
- Unusual destination port activity
- Alert spikes over time
- High-severity security alerts
