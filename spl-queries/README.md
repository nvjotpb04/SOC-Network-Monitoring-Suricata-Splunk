
# Splunk SPL Queries

This directory contains Splunk Search Processing Language (SPL) queries
used for security monitoring and Suricata alert analysis.

## Query Categories

The project uses SPL queries for:

- Suricata alert signature analysis
- Source IP analysis
- Destination IP analysis
- Destination port analysis
- Alert severity analysis
- Alert timeline analysis
- Network protocol analysis
- HTTP method analysis

## SOC Analyst Usage

SPL queries are used to search, filter, aggregate and analyze security
events collected by Splunk Enterprise.

The queries help analysts identify suspicious activity, investigate
alerts and correlate network security events.

## Note

The final query files in this directory will contain the actual SPL
searches used to create the corresponding SOC dashboard panels.
